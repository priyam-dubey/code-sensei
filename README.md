Code Sensei

**Code Sensei** is a full-stack AI-powered code review tool. It analyzes your source code using Google's Gemini AI to identify logic bugs, suggest modern best practices, and calculate Big O complexity.

---

Features
* **AI Analysis**: Get instant feedback on your code from Google's Gemini 1.5/2.0 Flash models.
* **Modern UI**: A sleek, dark-themed dashboard built with Next.js 15+ and Tailwind CSS.
* **Smart Detection**: Detects logic flaws and performance bottlenecks automatically.
* **Big O Insights**: Provides algorithmic complexity analysis for your functions.

## 🛠️ Tech Stack
- **Frontend**: Next.js 15, Tailwind CSS, Axios, Lucide-React
- **Backend**: Node.js, Express, TypeScript, @google/generative-ai
- **AI Engine**: Google Gemini API
